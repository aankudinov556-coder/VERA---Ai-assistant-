# VERA — ИИ-компаньон

Цель: ассистент для ПК (Windows 11) и телефона с синхронизацией, локальными и API-моделями,
голосовым управлением, командами из блоков и кристальным (glass/crystal) дизайном.

## Стек
- Tauri 2 (Rust) + React + TypeScript + Vite
- Модели: OpenRouter (основной), Ollama/llama.cpp (запасной, локально), Claude API
- Голос: whisper.cpp (STT), openWakeWord, Piper (TTS)
- Хранилище: SQLite + CRDT, синхронизация через E2E-шифрованный relay
- Блоки команд: React Flow + JSON-сценарии

## Целевое железо (учитываем)
i5-3330S (без AVX2), GTX 760 2 ГБ, 8 ГБ DDR3 → API по умолчанию, локально только модели 1.5–3B,
режимы эффектов (full / lite / off), сборки через CI.
